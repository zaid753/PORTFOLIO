## ⚙️ Running Locally

Clone the repository:

```bash
git clone https://github.com/zaid753/PORTFOLIO.git
```

Navigate into the project:

```bash
cd PORTFOLIO
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
